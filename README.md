# scary-videos

Daily scary story videos – hosting for automated YouTube Shorts & TikTok uploads.

- `engine/make_survival.py` – animated survival/horror Shorts (HUD, thermal camera, searchlights…), story format in its docstring and `engine/example_story.json`
- `engine/make_video.py` – narration (Kokoro), sound effects and ambience helpers
- `history/` – one file per day: title, premise, recipe, stats
- `videos/` – the latest video (older ones are removed after they are published)
